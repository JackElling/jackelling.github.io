# Personal site

An antique-map / atlas theme — the home page is an illustrated map you click through to the other pages.

A small personal website built with plain HTML, CSS, and JavaScript —
no build tools or frameworks required. Hosted for free on GitHub Pages.

## Structure

```
index.html      Home — overview and quick facts
college.html    College and things I've done
hobbies.html    Collections, hobbies, and writing
css/style.css   All styling
js/script.js    Light/dark theme toggle
```

## Editing

Every file is plain text — open any `.html` file in a text editor and
replace the bracketed placeholders like `[Your Name]` with your own
details. All three pages share `css/style.css`, so a style change in
one place updates the whole site.

## Running locally

Just open `index.html` in a browser. No server or build step needed.
